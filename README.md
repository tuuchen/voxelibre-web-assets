# VoxeLibre browser assets

Versioned WebAssembly engine and full VoxeLibre content assets used by the
Tuuchen Games browser release.

- Luanti engine source: https://github.com/ford442/luanti_wasm
- VoxeLibre source: https://github.com/VoxeLibre/VoxeLibre
- Build-specific license notices are included in the deployed launcher.

The files in this repository are distributed under their respective upstream licenses.

Large current builds are attached to GitHub Releases so they can be streamed
directly into Cloudflare R2 without Git's 100 MB object limit. See the matching
`RELEASE-*.md` manifest for exact sizes, SHA-256 hashes, source revisions, and
browser acceptance results.
